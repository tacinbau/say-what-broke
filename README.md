One line of honest, funny error copy. Run `node main.ts` — it prints the entry and writes it to `/output/entry.txt`.

## The entry

> The database took your request, locked the door from the inside, and swallowed the key. Your data is safe — we just can't reach it. Try again in a minute.

It names the real failure (the database is unreachable), reassures the user their data is safe, and tells them what to do next.
